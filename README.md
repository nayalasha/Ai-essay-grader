# 📝 AI Essay Grader

An AI-powered essay grading application built with Python and CustomTkinter. This project analyzes essays, provides feedback, calculates scores, and helps students improve their writing skills.

---

## ✨ Features

- 📝 Essay text input
- 📊 Essay scoring system
- 📖 Word count analysis
- 📄 Sentence count analysis
- 📚 Paragraph count analysis
- 💡 Writing improvement suggestions
- 🎯 Essay structure evaluation
- 🤖 AI-powered feedback *(planned)*
- 🎨 Modern desktop interface with CustomTkinter

---

## 🛠 Technologies Used

- Python
- CustomTkinter
- Git & GitHub
- OpenAI API *(planned)*
- NLTK *(planned)*
- TextStat *(planned)*
